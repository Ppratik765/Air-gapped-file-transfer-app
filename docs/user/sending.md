# Sending Files and Text

WaveDrop provides two primary sending paradigms: **Continuous Optical Fountain Streaming** and **WebRTC High-Speed Direct Transfer**.

---

## 1. Optical Fountain Streaming

In Optical mode, the sender encodes the payload into a rateless stream of animated QR codes displayed on a canvas.

### 1.1 Payload Selection
- **File Transfer:** Supports arbitrary binary formats up to 64 MB (documents, archives, images, video). Compression (GZIP) is automatically evaluated and applied only when it reduces total byte count.
- **Text Snippets:** Transmits raw text snippets up to 16 KB directly.
- **Fullscreen Display:** Clicking or tapping the QR code expands it to fit the entire display dimensions, enabling greater physical scanning distances.

### 1.2 Transfer Optimization Controls
The **Transfer Settings** panel allows real-time tuning of the transmission stream:

| Parameter | Default | Recommended Tuning |
|---|---|---|
| **Transmission FPS** | 60 FPS | On standard 60 Hz displays or if the receiving camera experiences decode lag, reduce to 24–30 FPS. |
| **Bytes / Frame** | 2953 (QR Version 40) | Highest density. For greater physical distance or lower-resolution receiver cameras, decrease to 1465 (QR Version 27) or 857 (QR Version 18). |
| **Error Correction (ECC)** | Level L | Set to Level L because the Fountain Coding layer handles packet erasures mathematically, making in-frame ECC redundancy unnecessary. |
| **Display Dimensions** | 900 px | Constrained by viewport size; ignored in Fullscreen mode. |

## 2. WebRTC High-Speed Direct Mode

For transfers where physical air-gapping is not strictly required and maximum transfer rate is desired:

1. Click **WebRTC Mode** on the sender page.
2. Select your file (up to 64 MB in browser, up to 512 MB in the native Android app).
3. The sender generates an SDP Offer encoded in a high-contrast QR code.
4. Point the receiver camera to scan the Offer QR.
5. Tap **Scan Receiver Answer** on the sender and scan the Answer QR generated by the receiver.
6. The direct `RTCDataChannel` opens, streaming the binary payload at maximum local network bandwidth.

---

## 3. Wi-Fi Direct (P2P) Pairing (Android Native App)

When running the native Android application in an environment without an existing Wi-Fi network or mobile hotspot:
1. Tap **Discover Nearby Devices** in the Wi-Fi Direct section.
2. Select the target device from the discovered peer list.
3. The Android OS establishes a local Wi-Fi P2P group automatically.
4. Proceed with the WebRTC transfer across the established peer link.
